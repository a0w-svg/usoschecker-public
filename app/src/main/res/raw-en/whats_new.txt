• Desktop (Windows, Linux): the connection to USOS is fixed. The bundled Java runtime did not trust the university servers’ certificate, so sign-in, key registration, refresh and news did not work at all. Android carries the same root certificate for older system versions.
• More: fixed sections that were always empty because the app asked USOS for fields that do not exist: dormitories and allocation periods, mobility, placement tests, questionnaires to answer, statements, custom groups, and surveys and exam reports in the lecturer panel.
• Sign-in is no longer lost when the system stops the app while the browser is open: returning from USOS completes the connection even after a restart.
• When saved data cannot be read (lost key, damaged file), the app offers to reset local data instead of repeating the same error.
• Background refresh: Platon, reminders and widgets keep working when USOS is temporarily down; no pointless retries when the server asks for a pause.
• Security: revoking the API key sends the secret in the request body, not in the address; key registration refuses redirects and limits the answer size.
• Platon: a crash of the in-app browser no longer closes the whole app.
• Desktop: get the API key automatically from your email and revoke it when disconnecting; change notifications are in Polish, English and Ukrainian.
• The update check no longer fails when the saved release information is unreadable.
• Platon: read your messages in the app (an unread message asks first, because Platon then marks it as read), and a course shows its progress, grade and its assignments.
• Platon: choose which semesters to sync (the newest by default), for example to see last year's assignments.
• Platon settings: separate notifications for new assignments, grade changes and new messages, and an option to stop refreshing when Tasks opens.
• Under the hood: tasks and Platon handling were moved out of the main activity, and stored data now carries a format version with automatic migration (completed tasks always show 100% progress).
• More tests: concurrent writes and account switching in the repository, plus saved Platon page samples that will reveal a change of their layout.
• Faster background refresh: the app no longer decrypts and reloads your data on every refresh when nothing has changed.
• Much faster refresh: USOS and Platon fetch independent data at the same time (capped so the servers are not overloaded), and Platon assignments with a known deadline are not fetched again. After a sign-in error or rate limit, further requests stop.
• Lecturer detail windows (groups, attendance, theses, dormitories) are fully translated into Polish, English and Ukrainian.
• Release notes are now complete in English and Ukrainian.
• Platon in the app: assignments with deadlines, course progress, grades and messages from Platon in one place. Sign in once with one tap; the session renews itself.
• Notifications for new assignments, grade changes and new Platon messages, and for upcoming deadlines. Platon events also appear in the Changes screen.
• Class reminders work again after a phone restart and after an app update.
• The account screen is hidden from screenshots, and notifications no longer show their content on the lock screen.
• New look in Vistula colours: lighter cards, clearer headings and consistent buttons across the app.
• Simpler USOS connection: you only enter your e-mail, and the app registers the API key itself and opens the sign-in. After you approve access you return to the app automatically; the PIN remains as a fallback.
• Entering a key manually is now optional, and you set permissions in one place: Settings → USOS data access.
• When you disconnect the account you can revoke the API key in USOSapps right away.
• On the home screen: a countdown to task and exam deadlines.
• Simpler Payments: the amount due first and copying the account number, paid instalments collapsed below.
• Plan, More, Settings, Tasks, Messages and Absences in a new card layout.
• Fix for overlapping lines in large headings.
